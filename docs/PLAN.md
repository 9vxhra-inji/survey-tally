# 설문 집계기 계획서

## 목표

엑셀에서 머리글 줄까지 복사해 붙여넣으면 문항별 결과 표를 보여 주는 정적 웹 페이지를 `index.html` 하나로 만든다.

## 지켜야 할 조건

- 외부 라이브러리·외부 글꼴·분석 도구를 쓰지 않는다. 글꼴은 시스템 글꼴만 쓴다.
- 붙여넣은 데이터는 브라우저 밖으로 보내지 않고, 어디에도 저장하지 않는다.
  - 네트워크 요청 코드(`fetch`, `XMLHttpRequest`, `sendBeacon`, `WebSocket`)와 저장 코드(`localStorage`, `sessionStorage`, `indexedDB`, `document.cookie`)를 쓰지 않는다.
  - `Content-Security-Policy` 메타 태그로 외부 연결을 막는다(`default-src 'none'`).
  - 입력칸은 `autocomplete="off"`, `spellcheck="false"`로 둔다.
  - `<form>`을 쓰지 않아 제출로 데이터가 나갈 길을 없앤다.
- 저장소 맨 위에 빈 `.nojekyll` 파일을 둔다(GitHub Pages가 Jekyll 처리를 하지 않게).

## 집계 규칙

| 항목 | 규칙 |
| --- | --- |
| 입력 형식 | 엑셀 복사 형식: 칸은 탭, 줄은 `\r\n`·`\n`·`\r`로 나눈다. 엑셀이 큰따옴표로 감싼 칸(칸 안 줄바꿈·탭·`""`)도 한 칸으로 읽는다. |
| 첫 줄 | 머리글. 둘째 열부터가 문항 이름이다. |
| 첫 열 | 응답번호. 집계하지 않는다. |
| 유효 | 앞뒤 공백을 지운 값이 `1`·`2`·`3`·`4`·`5` 중 하나 |
| 빈 응답 | 비었거나 공백만 있는 칸 |
| 제외 | 그 밖의 값(`0`, `6`, `3.0`, `01`, `１`, `예` 등) |
| 칸이 모자란 줄 | 모자란 칸을 빈 응답으로 센다 |
| 평균 | 유효 응답의 합 ÷ 유효 응답 수, 소수 셋째 자리에서 반올림해 둘째 자리까지(예: `3.00`, `2.35`). 유효가 0이면 `-` |

계획서에서 정한 세부 판단(요청에 명시되지 않은 부분):

- 완전히 빈 줄(글자가 하나도 없는 줄)은 응답 줄로 치지 않는다. 엑셀 복사본 끝의 줄바꿈 때문에 생기는 빈 줄이 응답으로 잡히지 않게 하기 위함이다. 탭만 있는 줄은 응답 줄로 보고, 칸은 모두 빈 응답이 된다.
- 머리글보다 칸이 많은 줄은 넘치는 칸을 무시한다.
- 문항 이름은 앞뒤 공백을 지워 보여 주고, 비어 있으면 `(이름 없음 N열)`로 보여 준다.
- 평균은 부동소수 오차를 피하려고 정수 연산(합×100÷수를 반올림)으로 구한다.

## 구조

- `index.html`
  - `<script id="tally-core">`: 계산 로직만. DOM을 건드리지 않는 순수 함수(`parseTable`, `classifyCell`, `formatAverage`, `tally`)를 `SurveyTally` 객체로 내보낸다.
  - `<script id="tally-ui">`: 화면. 입력을 읽어 `SurveyTally.tally`를 부르고 결과를 `textContent`로 표에 그린다(`innerHTML` 미사용).
- `test/core.test.js`: `index.html`에서 `tally-core` 스크립트를 꺼내 Node `vm`에서 실행하고 계산 규칙을 시험한다.
- `test/page.test.js`: `index.html`에 외부 주소·네트워크·저장 코드가 없는지, CSP가 있는지, `.nojekyll`이 빈 파일인지 확인한다.
- `package.json`: 의존성 없이 `npm test` → `node --test`.
